Finansal Analiz & Takip Terminali (V10)
Financial Analysis & Tracking Terminal
Bu proje, Python ve Streamlit kullanılarak geliştirilmiş, gerçek zamanlı piyasa verilerini analiz eden profesyonel bir finans terminalidir.

This project is a professional financial terminal developed using Python and Streamlit, designed to analyze real-time market data.

🚀 Özellikler / Features
Canlı Veri Takibi / Real-Time Tracking: BIST 100, Altın, Dolar ve Kripto para verilerinin anlık izlenmesi.

Teknik Analiz / Technical Analysis: RSI, SMA gibi indikatörlerle hisse senedi performansı ölçümü.

İnteraktif Grafikler / Interactive Charts: Plotly kütüphanesi ile kullanıcı dostu, detaylı grafikler.

Kişiselleştirilmiş Panel / Personalized Dashboard: KPSS geri sayım sayacı ve finansal not defteri entegrasyonu.

🛠️ Kullanılan Teknolojiler / Tech Stack
Language: Python 3.9+

Framework: Streamlit

Data Source: Yahoo Finance (yfinance)

Visualization: Plotly, Pandas

Technical Analysis: Pandas-TA
